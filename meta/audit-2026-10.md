Every fenced `kelp` block under `language/`, `stdlib/`, `libraries/`, `tooling/`,
`compiler/`, `getting-started/`, `examples/` and `reference/` that is a complete
program (`fun main`) was extracted, built and run against the prebuilt compiler
`kelpc-docs` (a debug build of compiler `main`), and each one was compared with
what its page says. Blocks that are not complete programs but whose page claims a
specific output or a specific compile error were assembled and checked by hand.
This page records the result: the block, where it is, the verdict, and what was
done about it.

**Status: a record of one run, not a live check.** The verdicts were true of the
compiler on `main` when the audit ran. They have not been re-run against later
releases, so a block marked as matching may now behave differently. To check a
block today, use the reproduction steps at the end of this page.

## How it was run

- Compiler: a prebuilt debug build of the compiler on `main`, named `kelpc-docs`
  in the commands below.
- Every program was compiled with no address-space limit of its own, then **run
  under hard limits**: `( ulimit -v 1048576; ulimit -t 10; timeout 10 ./prog )`,
  1 GiB of address space, 10 seconds of CPU and 10 seconds of wall clock, with
  stdin from `/dev/null`. A program that hits a limit is a finding, not something
  re-run with a higher one; none did.
- The extracted sources and their outputs live in `scratch/` in the wiki
  worktree (untracked, not committed). A program number in the table is the
  1-based line of its opening fence in the page.
- Library examples were run against a clone of `Lilly/fpl` placed at
  `deps/`, at its `unreleased` revision `be22818`; the compiler resolves
  `impl "deps/<name>/lib"` relative to the source file, so each program was run
  from a directory carrying a `deps/` entry per library the page names.
- Programs whose page requires a manifest (`[unsafe] modules`, `[caps]`,
  `[target] mode = "freestanding"`) were run inside a project carrying exactly
  the section the page shows.
- Nothing in this audit changed compiler code, compiler tests or this
  worktree's `changelog.md`.

## Suspected compiler bugs

None. Every block that failed to build was a page error, a missing manifest
section the page itself documents, or a stale dependency; every wrong output was
a stale page. One program was written to check the `for` rule (a `List` grown
inside a `for` over itself). It is refused at **compile time**
(`error: cannot mutate 'xs' while iterating over it`), so it was never run
unbounded, and no program from this audit mutates a list while iterating over it
at run time.

## Dependency drift (not the page, not the compiler)

`Lilly/fpl`'s `discord` library does not build against this compiler, at either
of its revisions:

- The `unreleased` revision (`be22818`) and the `main`/26.09.2 revision
  (`e502aae`) both match a `ws.WsErr` with only `Dial` and `Handshake`, so
  building any program in `libraries/discord.md` stops at
  `deps/discord/lib.kp:4120` with
  `error: this 'when' is not exhaustive: 'Tls' of enum 'std.ws.WsErr' has no arm`.
- The `unreleased` revision then calls `ws.try_connect_secure`, which `std/ws`
  no longer exports; the URL-aware spelling is `ws.try_connect_url`. Fixing the
  missing `Tls` arm alone would not make it build.

The page's description and the standard library are now consistent with each
other; the library needs its own update, in its own repository. It is recorded
here rather than silently patched, because a change to the library is out of
this worktree's scope.

## Compile-error and output claims re-checked

The pages name many diagnostics verbatim. Each claim below was reproduced with a
minimal program (several needed a small manifest) and compared with the page.
Everything matched; where the compiler says more than the page quotes, the extra
is noted and the page left alone.

| Claim (page) | Result |
| --- | --- |
| `error: cannot mutate 'xs' while iterating over it` (`language/control-flow.md`, `language/pitfalls.md`) | Exact, on the `for` line. |
| `error: cannot compare 'str' values with '=='` (`language/expressions.md`, `language/pitfalls.md`, `stdlib/str.md`) | Matches; the compiler continues the sentence with "a 'str' is a borrowed pointer, so this would compare addresses rather than text" and then names `str.eq`. |
| `error: 'Acquire' is not a variant of enum 'std.atomic.Ordering'` (`stdlib/atomic.md`, `stdlib/thread.md`) | Matches; the compiler appends a clause naming the only variant, `SeqCst`. |
| `error: the initializer is not constant: a 'i32' static is ...` (`language/statics-and-defer.md`) | Exact. |

## Reproducing a block

A page's program is a `kelp` fence; copy it to `p.kp` and run

```sh
kelpc run p.kp
```

or, for a program that touches a capability, a socket or the clock, build it and
run the binary under the same limits this audit used:

```sh
kelpc build p.kp -o p
( ulimit -v 1048576; ulimit -t 10; timeout 10 ./p )
```
